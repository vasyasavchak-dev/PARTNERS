# Partners — застосунок для телефона

Обгортка над вашою CRM на Google Apps Script. Відкривається як окремий застосунок
на телефоні й комп'ютері, без адресного рядка браузера.

Сама CRM залишається в Apps Script — тут лише оболонка з іконкою. Оновлення
підхоплюються самі: ставите нову версію в Apps Script, і застосунок одразу її показує.
Сторінку на GitHub міняти не треба.

---

## 1. Створити репозиторій

1. Відкрийте https://github.com/new
2. **Repository name** — `partners` (будь-яка назва латиницею)
3. Поставте **Public**, нічого більше не позначайте → **Create repository**

## 2. Завантажити файли

1. На сторінці репозиторію натисніть **uploading an existing file**
   (або **Add file → Upload files**)
2. Перетягніть **усі файли з цього архіву**: `index.html`, `manifest.webmanifest`,
   `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable.png`, `.nojekyll`
3. Унизу — **Commit changes**

Файл `.nojekyll` може не відображатися у списку — це нормально, він потрібен,
щоб GitHub не ховав службові файли.

## 3. Увімкнути GitHub Pages

1. **Settings** → ліворуч **Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `main`, папка `/ (root)` → **Save**
4. Через 1–2 хвилини вгорі з'явиться адреса виду:

```
https://ВАШ_ЛОГІН.github.io/partners/
```

Це і є посилання на застосунок.

## 4. Встановити на телефон

**Android (Chrome):** відкрити посилання → меню ⋮ → **Встановити застосунок**

**iPhone (Safari):** відкрити посилання → кнопка «Поділитися» → **На екран «Додому»**

**Комп'ютер (Chrome / Edge):** відкрити посилання → значок встановлення
в правому кінці адресного рядка

Ту саму адресу дайте партнерам — кожен входить під своїм логіном.

---

## Що варто знати

- **Оновлення CRM** підхоплюються самі. Ставите нову версію в Apps Script
  («Ввести в дію → Керувати розгортаннями → олівець → Нова версія») — і застосунок
  показує її при наступному відкритті.

- **Адреса CRM** прописана в `index.html`, у рядку `CRM_URL` на початку файлу.
  Міняти її треба лише тоді, коли ви створили **нове розгортання** замість
  оновлення наявного. Тоді замініть рядок і завантажте `index.html` на GitHub ще раз.

- **Перевірте `CRM_URL`** перед першим запуском: у файлі вже стоїть ваша поточна
  адреса, але якщо ви колись перестворювали розгортання — звірте її з тією,
  що показує Apps Script.

- **iPhone Safari** інколи забуває вхід усередині таких застосунків, тож раз на
  тиждень може знадобитися ввести логін і пароль ще раз. На Android такого зазвичай немає.

- **Щоб застосунок працював у вікні**, у `Code.gs` функція `doGet` має віддавати
  сторінку з `setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)`.
  У вашому коді це вже є — нічого робити не потрібно.

- **Іконка** — темно-зелений квадрат із літерою P. Щоб поставити свій логотип,
  замініть `icon-192.png` і `icon-512.png` на свої картинки тих самих розмірів
  і завантажте їх на GitHub.
